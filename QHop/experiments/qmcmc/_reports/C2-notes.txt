PART 1. CROSS-CUTTING FINDINGS

1.1 Surrogate acceptance formula (B1 claim) CHECKED [OWN].
  Setup: true energy E = E_sur + r, residual r ~ N(0, sigma^2) under pi_sur and decorrelated between s and s'. Ideal surrogate
  proposal = independence draw from pi_sur, MH weight w = exp(-beta r). At stationarity under the TRUE target the current state is
  tilted, r(s) ~ N(-beta sigma^2, sigma^2), while the proposal has r(s') ~ N(0, sigma^2). With m = beta^2 sigma^2, X = beta(r'-r)
  ~ N(m, 2m). Acceptance = P(X<0) + E[exp(-X); X>0] = Phi(-sqrt(m/2)) + exp(-m+m) Phi(-sqrt(m/2)) = 2 Phi(-beta sigma/sqrt2).
  Values: beta sigma 0.5 -> 0.724, 1 -> 0.480, 2 -> 0.157, 3 -> 0.034, 5 -> 0.0004. Monte Carlo check (2e5 draws): 0.723, 0.479,
  0.157. B1's formula and numbers are correct for Gaussian decorrelated residuals. Caveats: (i) it is the residual-only factor;
  a symmetric QeMCMC proposal that is not a draw from pi_sur also pays rejections from surrogate-energy changes on top; (ii) with
  correlated residuals (smooth surrogate error) local moves see much smaller effective sigma, which favours local/DA-local moves
  over long jumps. Consequence: in every expensive-energy row the far-jumping quantum proposal and the classical surrogate
  independence sampler pay the SAME residual penalty, and the classical one has fully decorrelated proposals.

1.2 Delayed acceptance / surrogate transition is the fair rival for every surrogate row [LIT + OWN].
  Christen and Fox, "Markov chain Monte Carlo using an approximation", J. Comput. Graph. Stat. 14(4), 795-810 (2005),
  doi 10.1198/106186005X76983 (verified bibliographically, see Part 3). With the same cheap surrogate, classical PT on the
  surrogate gets t_E / 3e-8 s surrogate flips per true call for free in wall-clock terms: 1.3e7 flips at t_E = 0.4 s, 3e7 at 1 s.
  For surrogates on <=200 spins (and for exact block heat-bath of a 20-spin surrogate group in 1e-2 s) this is a near-exact
  pi_sur sample per true call. The quantum proposal can only win if pi_sur itself is classically hard to sample in that budget, or
  if it has a structurally better acceptance against the true target (no argument exists). Applied to B2-09, B5-03, B5-08, B5-11,
  K23 consistently.

1.3 NEW bound that kills coarse-grained single-group variants at feasible group sizes [OWN, derivation].
  Let P_g be any pi-reversible kernel that changes only the spins in group g (ideal P2 single-group QeMCMC with Metropolis accept
  is one). Let Pi_g be exact heat-bath on g: (Pi_g f)(x) = E_pi[f | x outside g], an orthogonal projection in L2(pi).
  For any f write f = h + u with h = Pi_g f. P_g h = h (h does not depend on spins in g), so the Dirichlet form
  E_Pg(f) = <f, (I - P_g) f> = <u, (I - P_g) u> <= 2 ||u||^2 = 2 E_Pig(f), because the spectrum of a reversible P_g lies in [-1,1].
  Averaging over the same random group law: E_Q(f) <= 2 E_HB(f) for all f, hence gap(QeMCMC-group) <= 2 gap(exact-group-heat-bath).
  So the per-step advantage S of any group-confined quantum proposal over exact block heat-bath on the same groups is at most 2.
  Cost of exact block heat-bath with Gray-code incremental energies ~10 ns per state [OWN estimate]: k=8 2.6e-6 s, k=12 4e-5 s,
  k=16 6.6e-4 s, k=20 1e-2 s, k=24 0.17 s, k=28 2.7 s, k=30 11 s.
  Required step advantage vs exact heat-bath, single chain IBM 3 s: k=12 7e4, k=16 5e3, k=20 3e2, k=24 18, k=28 1.1, k=30 0.3.
  With noise (pessimistic, dense F at 12 gates per coupling): k=20 3e4, k=24 1e4, k=28 1e4, k=30 1e4; even with Helios error 8e-4
  and 3 s per step at k=30: 18. Batched B=1000 (3.25e-3 s per chain): realistic k=20 0.31, k=24 0.02, but pessimistic k=20 30,
  k=24 15, k=30 10. Since S <= 2 and the noisy requirement is >= 10 at every k, single-group QeMCMC cannot beat exact group heat-bath
  in wall-clock at any group size where the circuit has non-negligible fidelity; at k >= 20 the classical side would in any case
  switch from enumeration to a short inner MCMC on the group (1e5 flips in 3 ms), which near-equilibrates a 20-30 spin conditional
  unless the conditional itself is glassy. The bound needs reversibility; P2's fixed-order sequential sweep is not reversible and is
  not covered by this exact statement (expected to behave similarly, unproven). This is used in B2-02, B2-03, B5-01, B5-08.

1.4 Batching fairness [OWN]. Batching divides the latency floor but the classical side batches as well; for expensive-energy ML
  rows (B2-09) GPU evaluates B chains' dataset passes as one GEMM (~5e-8 s per chain), so batching returns the problem to the
  cheap-energy regime. Batching is used in ML rows only (B2-01..06, 08, 13, 16, 18, 19) and stated in each row.

1.5 Noise [P1 SI + OWN]. Surrogate-driven proposals inherit hardware asymmetry (readout relaxation), and the Metropolis step does
  not correct a non-symmetric proposal; a residual bias must be measured (K3 calibration). This applies on top of F.
