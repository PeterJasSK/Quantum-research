(a) B3-09 Ewald ionic ordering: is the classical competitor really weak?  ANSWER: NO. Verdict changed SIMULATE MORE -> KILL.
  Verified literature:
  - Xie, Zhong, Barroso-Luque, Ouyang, Ceder, "Grand-canonical Monte-Carlo simulation methods for charge-decorated cluster
    expansions", arXiv:2210.01165, https://arxiv.org/abs/2210.01165 (PDF https://ceder.berkeley.edu/publications/2022_xie_charge-balanced_sgc.pdf).
    VERIFIED: table-exchange (TE, small charge-conserving multi-site excitations drawn from an exchange table) and square-charge
    bias (SCB, temporary drift from neutrality) are proposed for the GRAND-/SEMI-GRAND-canonical ensemble. The paper states that
    a canonical run fixes each species' composition and uses two-site swaps. No quantitative speedup vs a named baseline in the
    abstract.
  - smol implements it as the "table-flip" step with an Ewald-including CE: https://cedergrouphub.github.io/smol/notebooks/running-charge-balanced-gcmc.html
    and JOSS doi:10.21105/joss.04504 (canonical and semigrand MC).
  - Realistic DRX SRO practice: "Short-Range Order and LixTM4-x Probability Maps for Disordered Rocksalt Cathodes",
    arXiv:2508.08112, https://arxiv.org/html/2508.08112v1 . VERIFIED: canonical MC (ATAT emc2), 32^3 = 32,768-site cells,
    1e4 flips/site equilibration + 1e4 averaging, fine T grid 0.8-1.2 Tc, reported at T/Tc = 1.1, heating/cooling hysteresis
    checks; no general slow-mixing complaint (only a 50/50 choice between layered and spinel-like LRO below Tc for some J ratios,
    a degeneracy issue). That paper's CE has no explicit Ewald term; Ewald CEs are standard in the Ceder group (Ji et al., Nat.
    Commun. 10, 592 (2019), https://www.nature.com/articles/s41467-019-08490-w, CE-MC, Ewald use not confirmed by me).
  Reasoning [OWN]:
  - In the canonical ensemble every two-site swap conserves composition and therefore total charge. Charge balance is a problem
    only for the semigrand ensemble (voltage curves), and there TE/SCB exist and work in a released code. So "single-site moves
    forbidden" does not make the canonical competitor weak; any-pair swaps + PT is the baseline, same as B3-07.
  - Frustration: Ewald-dominated cation SRO at synthesis temperature (MEDIUM-HIGH, T/Tc~1.1, which is what sets the quenched SRO
    that controls Li percolation) is routinely equilibrated at 3e4 sites. The glassy LOW-T Coulomb regime where SK-like gap
    transfer [SPEC] might matter is not what the battery engineer needs.
  - Quantum side: 8-12 sites x 2-3 qubits = 24 qubits dense; ~1.5e4-2.3e4 CZ per proposal (repo scaling) -> F ~ 1e-13; even on
    Helios (8e-4 2q error) F = (1-8e-4)^1.5e4 ~ 6e-6 [OWN]. Toy only (hardware fit 1).
  Break-even: t_C 1 us; S* = 0.1/1e-6 = 1e5 (Helios opt) / 3/1e-6 = 3e6 (IBM real) / 3e6/9.1e-14 = 3e19 (pess, N_2q 1.5e4).
  Likelihood: wall 0.1% (0-0.5) / steps 5% (1-12). The only residual question (do conserving mixers give a sector gap advantage on
  dense frustrated couplings?) is folded into the B3-07 Wave 4 experiment, which includes a dense Ewald-like instance.

(b) B3-01 cold-end quantum moves inside PT: cost-weighted mixture ratio.  [OWN derivation, standard Dirichlet-form facts]
  Kernel at a cold replica: P_p = p Q + (1-p) L, Q = quantum proposal + Metropolis, L = classical single-proposal update (PT
  sweeps decomposed per proposal), both reversible w.r.t. pi_k. Detailed balance: fixed-p mixture of reversible kernels is
  reversible; PT swaps unchanged; p must not be adapted from chain history.
  Dirichlet forms are linear in the kernel: E_P(f) = p E_Q(f) + (1-p) E_L(f). Hence
     gap(P_p) >= p gap_Q + (1-p) gap_L            (mixture never hurts per step)
     gap(P_p) <= p E_Q(f_L)/Var(f_L) + (1-p) gap_L <= 2p + (1-p) gap_L   (f_L = slowest mode of L; spectrum of Q in [-1,1]).
  Cost per step c(p) = p t_Q + (1-p) t_C. Time efficiency eta(p) = gap/c is bounded by a linear-fractional function of p, which
  is maximised at an endpoint:  eta(p) <= max( gap_L / t_C , 2 / t_Q ).
  So the mixture beats pure classical in wall-clock ONLY IF 2/t_Q > gap_L/t_C, i.e. tau_L = 1/gap_L > R/2, R = t_Q/t_C, AND
  only if a single quantum move nearly fully decorrelates the classical slow mode (Rayleigh quotient O(1)).
  Numbers: one quantum move costs R = 3 s / 30 ns = 1e8 proposal-equivalents (IBM realistic, dense n<=100), 3.3e6 (Helios opt);
  the brief's "1e7-1e8 classical flips" is the right range. To keep the quantum share of wall-clock <= 50% requires
  p <= 1/R ~ 1e-8 (one quantum move per 1e6 sweeps at n=100). PT equilibrates SK up to N=4096 at T>=0.4 [A5, arXiv:1003.6086];
  at n=100 that is of order 1e4-1e6 sweeps = 1e6-1e8 proposals = 0.03-3 s of CPU, i.e. comparable to ONE quantum step.
  Required condition tau_PT > 5e7 proposals essentially never holds where the quantum circuit can be run (n<=30), and at n=100
  the P1 fit extrapolates to gap_Q ~ 2^(-0.264*100) ~ 1.1e-8 per step [SPEC extrapolation], so Q itself is nowhere near an
  independent sample. Wall-clock: no regime. Steps-only (ignoring cost) the mixture is the fair test the programme lacks; keep
  as SIMULATE MORE merged with K0 (Wave 4 nomination 1).
  S* row values: 3.3e6 / 1e8 / 5e8 (N_2q 800; repo-scaled n=10, 3,700 CZ -> 1.6e11).

(c) Conserved-quantity mixers (XY, ring exchange): symmetry and Trotter cost.  [OWN, checked against repo code]
  Exact unitary: XX+YY = 2(s+s- + s-s+) has real 0/1 entries in the Z basis; H_prob diagonal real; ring exchange
  (S+S-S+S-S+S- + h.c.) real 0/1. So H is real symmetric, U = exp(-iHt), U^T = exp(-i H^T t) = U, and
  Q(s->s') = |<s'|U|s>|^2 = |<s|U|s'>|^2 = Q(s'->s). Exact symmetry within the conserved sector, P1's argument carries over.
  Trotterised circuit: each factor exp(-i theta G_k) with real symmetric G_k is transpose-invariant, so the transpose of a
  product is the REVERSED product. The circuit proposal is exactly symmetric iff the gate sequence is palindromic (or the
  palindromic structure survives up to commuting reorderings). The repo trotter_circuit (qemcmc.py:98) uses D/2 M D/2 blocks:
  palindromic because all diagonal terms commute and the RX layer commutes. With an XY mixer, XY terms on edges sharing a site do
  NOT commute, so the mixer layer itself must be palindromic, e.g. ring: M_even(dt/2) M_odd(dt) M_even(dt/2) (~1.5x gates);
  all-to-all with an n-1 colour edge colouring: palindromic colour order (~2x gates).
  IBM native gates RZ (diagonal), SX = (1/2)[[1+i,1-i],[1-i,1+i]] (symmetric), X, CZ (diagonal) are each transpose-invariant, so
  the compiled circuit's transpose is the reversed compiled circuit. Transpiler optimisation and SWAP routing generally destroy
  palindromy -> Q != Q^T even without noise (the repo already has asymmetry() to measure this). Cheap exact fix: with
  probability 1/2 run the circuit, with 1/2 run its reverse: Q_mix(s->s') = (|U_s's|^2 + |U_ss'|^2)/2 is symmetric for ANY
  compiled order in the noiseless case [OWN]. Under noise the reversed circuit's channel is not the transpose of the forward one,
  so a residual bias remains; Pauli twirling as in P1 SI. Leakage out of the sector: pi = 0 there, rejected, safe; but it lowers
  acceptance. Postselecting on the sector does not restore symmetry under noise.
  Cost [OWN]: XX+YY gate = 2 CZ; fused with ZZ on the same edge, a generic 2q gate <= 3 CZ.
   - XY ring n=12 (heavy-hex has 12-qubit cycles, so a ring embeds natively): per Trotter step ~36 CZ (XY, palindromic) +
     24-48 CZ (CE pairs) ~ 90 CZ; x 22 steps ~ 2,000 CZ -> F 0.018.
   - XY all-to-all n=12: 66 pairs x 3 CZ (+ fused SWAP network) ~ 200-400 CZ/step -> 4,400-8,800 CZ -> F 1.5e-4 to 2e-8.
   - Ring exchange hexagon: CNOT ladder (~10 CNOT) maps it to an RX on one qubit controlled on 5 qubits matching a pattern;
     5-control RX without ancilla ~40-60 CNOT -> ~50-70 CZ per hexagon per step. Pyrochlore with N sites has N hexagons (each
     site in 6 hexagons of 6 sites), so a 16-site cell has 16 hexagons ~1,000 CZ/step, x1.5-2 palindromic, x2 routing ~3,000/step,
     x10 steps ~3e4 CZ -> F ~ 8e-27. Unrunnable; hardware fit 0.
  Conclusion: conserving mixers are the correct, exactly reversible way to impose hard constraints in QeMCMC (method note
  worth keeping), but the only cheap one (XY) is the one whose classical competitor (any-pair swap) is also free.
