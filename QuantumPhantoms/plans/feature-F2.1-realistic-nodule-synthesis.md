## 1. Why (Step Goal)

**Before.** `lesion.py` builds a threshold sphere with a uniform HU fill; `insert.py` pastes it on a hard mask with white noise and no blur. Result: a round, flat, razor-sharp disc that does not read as a real nodule (the F3.1 demo exposed this).

**After.** The nodule is generated by a reverse-engineered **procedural CT pipeline** (the classical half of what GAN/diffusion methods learn), closing the five realism gaps:
1. **Irregular shape** — sphere radius displaced by a smooth 3D random field (lobulation) + sparse radial spikes (spiculation), driven by `margin`.
2. **Heterogeneous interior** — a correlated random texture field around the type's mean HU, not a constant.
3. **Partial-volume edge** — a soft sub-voxel coverage (alpha) boundary, not a binary mask.
4. **Scanner blur** — the inserted region is convolved with a point-spread Gaussian (reconstruction-kernel blur) — the main de-sharpening fix.
5. **Correlated noise** — blurred noise matched to local background σ, replacing white noise.

Crucially, every random choice in this pipeline is **seeded from the tile's certified-quantum bitstring** (from `QuantumRun.raw_bits`), so the exact shape and texture are quantum-sourced too — the Tier-1 provenance claim now covers the lesion's morphology, still with zero training. This is the "useful realistic image" milestone; the later step (**F4**, parent §5.2.5) replaces the seeded *renderer* with a quantum *process* that grows the morphology.

## 4. Technical Decisions

Adopts epic §3 + the F1/F2/F3 decisions verbatim. Feature-specific:

| Component | Choice / Implementation |
|---|---|
| Method | **procedural** reverse-engineering of the phantom-synthesis pipeline (bioRxiv *Anthropomorphic Pulmonary CT Phantoms*): deform sphere → implant texture → soft edge → insert → blur → noise. ML papers (CT-GAN, 3D cGAN) are the quality reference only. |
| Shape | base sphere radius × (1 + Σ low-order harmonic/noise terms) for lobulation + roughness; `spiculated` adds sparse radial Gaussian spikes. Amplitudes keyed to `margin`. 3D blob (central slice inserted, F4-extensible). |
| Interior | HU = type-mean + correlated field via `gaussian_filter(normal_noise, σ_tex)`; per-type: solid (textured), GGO (low mean, soft radial falloff), part-solid (core sub-region + halo), calcified (sparse high-HU speckles). |
| Edge | `build_lesion` returns continuous `alpha ∈ [0,1]` (smoothstep of signed distance to the deformed contour, feather ≈ 1.5 vox) — the partial-volume cue. |
| Insertion | `insert_lesion` composites `out = bg + delta·alpha` (HU) / intensity-scaled for PNG; then **PSF blur** `gaussian_filter(region, σ_psf)` (`--psf`, default 0.7 px); then **correlated matched noise** (`gaussian_filter` of noise scaled to local σ). |
| Quantum seed | per-tile seed = integer from `QuantumRun.raw_bits[k]` (certified bitstring) XOR `shot_index`; fallback to the classical `--seed` when `raw_bits` is empty (PRNG). Recorded as `morphology_source`. |
| numpy 2.x | use `np.ptp(x)` not `x.ptp()` (removed in numpy 2.x — hit during prototyping). |
| Defaults | `--psf 0.7`, texture σ scaled to radius; `--ct-source bundled` stays default. |

**Conventions & Notes:**
* Code stays in the package layout (`f2_imaging/`); run via `python -m`. `Lesion` dataclass (in `lesion.py`) gains an `alpha` array; `central_slice` returns `(delta2d, alpha2d)`.
* No new dependency (scipy already present).
* Honest-label: add that shape+texture are seeded from the same certified-quantum measurement (QRNG runs); it remains a **classical rendering** — no claim of a quantum image, and the morphology realism is procedural, not learned.
* Keep it deterministic given (quantum bits, `--seed`, `--psf`) so a run reproduces.
