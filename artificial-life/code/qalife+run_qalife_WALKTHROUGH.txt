Step 1 — analytic genotype ⟨σz⟩: _z_geno_chain(4, thetas, True)

  z = [0,0,0,0]
  for k: base = 0.0 if (k==0 and founder_equator) else (1.0 if k==0 else z[k-1]); z[k]=cos(θ_k)*base
  - k=0: founder on equator → base=0 → z0 = cos(θ0)·0 = 0.
  - k=1: base=z0=0 → z1=0. k=2,3: also 0.
  - All zero. Genotype sits on the equator (⟨σz⟩=0) the whole line — that's what makes it a superposition chain (needed for the witness). Used next to set the phenotype prep angle.

  Step 2 — build_population loop, exact gate order

  Per individual g,p = 2k, 2k+1; age = 6−k; angle0 = acos(z_geno[k]) = acos(0) = π/2; aged = max(0, π/2 − δ·age):

  k=0:  ry(π/2, q0)      # FOUNDER: |0>→ on equator (|+>-like)
        ry(θ0,  q0)      # MUTATION g0     (θ0 small)
        ry(0,   q1)      # PHENOTYPE+DEATH p0   aged0 = max(0, π/2 − 6·π/8) = max(0,−π/4)=0
  k=1:  cx(q0,  q2)      # SELF-REPLICATION g0→g1  (partial σz clone, CNOT)
        ry(θ1,  q2)      # MUTATION g1
        ry(0,   q3)      # PHENOTYPE+DEATH p1   aged1 = max(0, π/2 − 5·π/8)=0
  k=2:  cx(q2,  q4)      # SELF-REPLICATION g1→g2
        ry(θ2,  q4)      # MUTATION g2
        ry(0,   q5)      # PHENOTYPE+DEATH p2   aged2 = π/2 − 4·π/8 = 0
  k=3:  cx(q4,  q6)      # SELF-REPLICATION g2→g3
        ry(θ3,  q6)      # MUTATION g3
        ry(π/8, q7)      # PHENOTYPE+DEATH p3   aged3 = π/2 − 3·π/8 = π/8 ≈ 0.393

  Phenotype/death math: phenotype prepped from |0⟩ by ry(aged). ⟨σz⟩ = cos(aged). Aging subtracts δ·age from the angle → drives it to 0 → |0⟩ = dark = dead.
  - p0,p1,p2: aged=0 → stay |0⟩ → ⟨σz⟩=+1 → dead.
  - p3: aged=π/8 → ⟨σz⟩=cos(π/8)=0.924 ≥ 0.80 → also dead (youngest, barely).
  - → this is why pop alive~0/4 at steps=6 unitary.

  Genotype line = GHZ-like chain: founder ry(π/2) puts g0 in superposition; each cx(g_{k-1},g_k) spreads it → (|0000⟩+|1111⟩)/√2-type state across q0,q2,q4,q6, tilted by the small mutations. This entanglement is the quantum signal.

  Note (unitary arm): phenotype is a product state prepped by ry — not entangled to its genotype (no cx(g,p) here; that only happens in the damping arm). So the phenotype carries no genealogical entanglement — it's the classical/diagonal observable. The
  witness lives purely on the genotype qubits.

Step 3 — INTERACTION sweep (nn)

  interaction_partner(k,4,"nn") = k−1 (None for k=0). Swaps run in order:
  k=1: swap(pheno_q(1), pheno_q(0)) = swap(q3, q1)
  k=2: swap(pheno_q(2), pheno_q(1)) = swap(q5, q3)
  k=3: swap(pheno_q(3), pheno_q(2)) = swap(q7, q5)
  These overlap (share q3, q5) → a cascade, not disjoint pairs. Trace phenotype values P0..P3 on (q1,q3,q5,q7):
  start:        q1=P0 q3=P1 q5=P2 q7=P3
  swap(q3,q1):  q1=P1 q3=P0
  swap(q5,q3):  q3=P2 q5=P0
  swap(q7,q5):  q5=P3 q7=P0
  final:        q1=P1 q3=P2 q5=P3 q7=P0
  → founder phenotype P0 shifts to q7; the rest cyclically shift down. (All ~dead here, so alive-count unaffected.)

  Step 4 — back in build_measured: readout prep

  q4._bar(qc, annotate, "X-basis (witness)")   # no-op unless --dump-circuit
  for k in 0..3: qc.h(q4.geno_q(k))            # H on q0,q2,q4,q6
  creg = ClassicalRegister(8, "c")
  qc.measure(range(8), creg)                    # q_i -> c_i
  - H on the 4 genotype qubits rotates their basis: measuring Z after H = measuring X. So genotypes come out in the X basis → their joint parity is ⟨X⊗X⊗X⊗X⟩ = the entanglement witness.
  - Phenotype qubits (q1,q3,q5,q7) get no H → measured in native Z → ⟨σz⟩ = alive/dead.
  - One 8-bit classical register c, q_i → c_i. Single circuit, dual-basis: witness (genotypes) + population (phenotypes) in one job.

  Result

  8-qubit circuit, shallow depth: 1 founder Ry + 3 CX (genotype chain) + 4 mutation Ry + 4 phenotype Ry + 3 SWAP + 4 H + 8 measure. Returned to the run block, which executes it for args.shots and tallies counts. Downstream: genotype bits → witness
  (xbasis_witness_from_counts), phenotype bits → alive-count.
